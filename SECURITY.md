# 安全问题 / Security

请使用 GitHub 的 [私密漏洞报告](https://github.com/joeseesun/aitv/security/advisories/new) 提交安全问题，附受影响提交、复现步骤和影响范围。不要在公开 issue 中发布密钥或可用于攻击演示站的细节。

项目当前维护 `main`。请使用自己的 Cloudflare 资源和服务凭据；真实密钥只通过环境变量或 Wrangler secrets 配置。

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/joeseesun/aitv/security/advisories/new). Include the affected revision, reproduction and impact. Do not publish credentials or exploit details in public issues. The maintained branch is `main`.
